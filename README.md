# GPGS Evidence Repository

Repositório dedicado ao Global Professional Growth System (GPGS), sua arquitetura AI-native e seu acervo de evidências profissionais verificáveis.

## Propósito

Servir simultaneamente como:

- fonte versionada de documentos constitucionais e estruturais;
- catálogo de evidências para candidaturas, portfólio e posicionamento internacional;
- laboratório de qualidade, custo, latência, confiabilidade e rastreabilidade de agentes.

## Governança

Career Strategist (`ADVISE`) propõe. Evidence Auditor (`VERIFY`) verifica. Career Maturity Assessor (`ASSESS`) avalia. Guardian (`APPROVE`) autoriza. JARVIS (`EXECUTE`) operacionaliza.

**Nenhuma evidência ou documento oficial deve ser publicado sem um veredito explícito do Guardian.** A submissão original deve ser preservada, mesmo quando reclassificada.

## Estrutura

- `constitution/` — baseline, autoridade e controle de mudanças.
- `skills/guardian/` — Skill do Guardian e seus evals.
- `evidence/` — evidências aprovadas, organizadas por ID; não incluir dados confidenciais.
- `schemas/` — contratos de evidência, claims e avaliações.
- `evals/` — casos e métricas dos agentes.
- `docs/` — arquitetura, decisões e operating model.

Notion permanece como System of Record operacional. Este repositório é o System of Record versionado para a camada estrutural.
