# Sprint S01 — Guardian Bootstrap & Evidence Inventory

**Período:** 2026-09-01 a 2026-09-07  
**Status:** Candidate / pending Guardian verdict

## Objective

Put the Guardian governance contract into operation, run the initial eval set, and inventory professional evidence candidates without publishing unapproved material.

## Work items

1. Define and approve the Guardian operational contract v0.1.0.
2. Run initial evals covering hypotheses, reclassification, conflicts, bypass attempts, and source preservation.
3. Inventory existing evidence candidates with claim, source, competency, evidence level, confidentiality, and gaps.
4. Prepare the first SQL maturity assessment.

## Acceptance criteria

- Every candidate record has a source trace.
- No official record exists without an explicit Guardian verdict.
- Original submissions are preserved.
- Eval results capture quality, correction rate, conflict detection, latency, cost, reliability, and traceability.
- No confidential evidence is committed.
